# Wedsent: product promise and next build, November 2026

This is the owner's intended platform, not a list of what happens to be built today. The prototype must never set the product's ceiling.

## One-sentence promise

Modern, distinctive digital wedding invitations that couples can customise in minutes, share as a link and use to manage replies without complexity. One straightforward price per wedding.

## Core journeys

1. **Discover:** homepage -> curated design collection -> exact guest preview -> try the chosen look.
2. **Create:** names and date -> event choices and cultural wording where relevant -> visual style and media -> guest preview -> review. Keep edits simple, save automatically, allow changing designs without data loss.
3. **Publish:** sign in -> one-time checkout -> reserve an invitation URL -> publish -> share by WhatsApp, text, email or QR. Private token options for guest-specific links.
4. **Guest:** open mobile link -> experience chosen motion with skip/reduced-motion -> see events, location, timings, dress code, calendar -> RSVP as household with plus-one, food or event choices when configured -> success and edit response flow.
5. **Manage:** host sees clear response totals, awaiting list, groups and reminders; event changes can notify affected guests. No unnecessary CRM language.
6. **After event:** optional photographer-curated photo hall, approved by hosts, with secure guest access and download controls. Scope and storage limits require commercial decision before launch.
7. **Print:** matching artwork, format selection, PDF export, crop/bleed and font/asset licence check. Browser A5 print preview today is not a professional print pipeline.

## Visual direction

- **Wedsent brand/site:** confident contemporary product identity. Geist Variable display and body, sharp spacing, restrained tones and product demonstration rather than oversized generic banner stacks. Do not apply romantic cursive fonts globally.
- **Invitation worlds:** separate typographic art directions. The first envelope design is maturing into earthy Vermilion, Monolith is structural, Nocturne is cinematic. All three need further genuine art direction and stronger print-ready assets.
- **Studio:** phone-first, live, interactive, frameless-feeling editing. Show only fields that matter for the task. Expose advanced options deliberately.
- **Motion:** envelope unfold, card/shutter reveal, press-and-hold/film-like entrance; each has meaningful touch, replay, skip and reduced-motion behavior. Never start audio without consent.

## Shipping phases

| Phase | Main delivery | Gate |
|---|---|---|
| A | Brand typography, commercial homepage, gallery and pricing page | Responsive visual review and no fake claims |
| B | Three design families with matched renderer, accurate thumbnails, mobile motion and artwork | Real user critique of visual quality, accessibility and long names |
| C | Auth, database, saved draft ownership, payment and publishing | End-to-end secure link persistence, idempotency and permissions |
| D | Guest group model, true RSVP, plus-one, multiple events, reminders | Household and restricted-event scenarios pass |
| E | Final export pipeline, optional guest photo hall, monitoring/pilot | Privacy, media costs and production proofs |

## Current state

Phase A is a visual/functional iteration. The pricing page displays a **provisional £39** one-time concept, not a final commercial promise. There is no checkout. The draft still persists only in the browser, and real guest publishing and RSVP collection are not live. Do not claim those functions work until completed end to end.
