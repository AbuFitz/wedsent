# Wedsent active visual system / November 2026

## Owner-approved direction

The owner approved a warm, editorial invitation concept after rejecting several prior generic marketing designs. References: owner-supplied Salega premium-serif specimen and Nookey fashion page (mood and typographic craft only), [Folira Lite](https://folira-lite.framer.website) floating rounded navigation and restrained layout, and an [ApertureAccordion Framer module](https://framer.com/m/ApertureAccordion-GRWRFV.js@LRyStYxTn3OP0jOxFtLm) supplied as an interaction cue. The exact code module could not be directly accessed, so our accordion is an independently implemented, accessible button-based component.

## System

- Primary near-black olive `#292b20`; parchment `#f8f5ee`; pastel sage `#d8dfce`, lilac `#ded4e2`, blush `#edc9bc`, butter `#f3e7bf`; terracotta action `#a75c40`.
- Current type foundation: Cormorant Garamond for display/brand and Manrope for controls. Both are commercially usable under their open font licences; any custom Wedsent wordmark must later be drawn as original outlined lettering and tested at small sizes. Never copy Salega's actual letterforms.
- Single elegant floating nav on marketing. Studio should retain task clarity and preview context, guest page should prioritise date/time/location/RSVP.
- Original generated `public/art/wedsent-organza.webp` supplies an atmospheric art-directed backdrop. No unlicensed photographer assets or paid Framer component code were copied.
- Expandable design panels are meant for gallery discovery: click/touch opens one panel, `aria-pressed` exposes state, active design leads into Studio. Mobile panels remain tappable. Respect reduced-motion preferences.
- Distinctive invitation experiences require actual rendered interactive opening states, real content hierarchy and configurable artwork; the first stylesheet pass is NOT final template architecture.

## Product truths

The marketing design, browser-local Studio, preview guest page and demo RSVP are executable prototypes. Persistent wedding accounts, publishing, event-specific private guest tokens, checkout, live RSVPs, server storage, music licence management and Photo Hall are not implemented. Never promote them as live.
